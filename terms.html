TERMS OF USE

制定：2026年10月　

この利用規約は、OTON LAB（オトン研究所。以下「当研究所」）が公開するウェブサイトと作品（SOLARIS ほか。以下「作品」）を利用するときの決まりです。作品を利用した時点で、この規約に同意したものとします。

1. 無料で使えます

作品は、どなたでも無料で利用できます。利用者の登録はいりません。

2. 再配布・転載はできません

「無料で使える」ことは、作品のプログラム（ソースコード）、画像、科学データ、3Dモデル、音声、文章などを自由に再配布してよいという意味ではありません。次のことはお控えください。

  • 作品やその一部を、複製して配布・販売・転載すること
  • 作品の画面や素材を、自分のものとして公開すること
  • 作品のサーバーに過度な負荷をかける使い方（自動での大量取得など）

作品の中で使っている第三者の画像・データ・3Dモデル・フォント・ライブラリの権利は、それぞれの権利者にあります。それらは各権利者が定める条件に従います。くわしくは著作権・データ出典をご覧ください。

3. 機関との関係について

作品は、NASA（アメリカ航空宇宙局）、JPL（ジェット推進研究所）、ESA（欧州宇宙機関）などの機関が公開しているデータや画像を利用しています。ただし、当研究所と作品は、これらの機関と提携しておらず、後援・承認・推奨を受けたものでもありません。

4. 内容の正確さについて

作品は、公開されている科学データをもとに、できるだけ正確に作っています。ただし、学びと楽しみのためのものであり、内容の正確さや完全さを保証するものではありません。航行・観測計画・防災など、安全や判断に関わる用途には使わないでください。

5. 端末に保存するデータとアクセス解析

作品によっては、表示を速くするためや設定を覚えておくために、データをお使いの端末のブラウザに保存します。保存したデータは、ブラウザの設定から消すことができます。

このサイトは GitHub Pages で公開しています。アクセスの記録は GitHub 社の方針に従って扱われます。

アクセス解析について

サイトと作品の改善のため、アクセス解析サービス GoatCounter を使い、見られたページ・おおよその流入元・画面の大きさなどを集計しています。GoatCounter は Cookie を使わず、広告のための追跡も行いません。集計した数値は運営者だけが確認し、個人を特定する目的には使いません。

6. 変更・停止

作品やこの規約は、予告なく変更・中断・終了することがあります。それによって生じた損害について、当研究所は責任を負いません。

7. 外部サイトへのリンク

作品や出典表示から、外部のサイトへリンクしています。外部サイトの内容については、それぞれの運営者の規約に従ってください。
